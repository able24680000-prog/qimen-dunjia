# 奇门遁甲桌面快捷启动器设计

## 目标

在 Windows 桌面创建名为“奇门遁甲”的快捷方式。用户双击后，启动器在后台启动本地奇门网站，并使用系统默认浏览器打开首页。

## 方案

- 快捷方式名称：`奇门遁甲`
- 快捷方式位置：当前 Windows 用户桌面
- 启动脚本位置：`qimen-website/scripts/start-desktop.ps1`
- 网站地址：`http://127.0.0.1:5174/`
- 项目目录：由启动脚本相对自身位置解析，不写死工作目录
- Node 启动程序：优先使用系统可用的 `npm.cmd`

## 启动流程

1. 检查本地网站是否已经在 `5174` 端口响应。
2. 如果已经运行，直接打开首页，避免重复启动进程。
3. 如果尚未运行，在隐藏窗口中执行 Vite 开发服务。
4. 最多等待 20 秒，确认首页可以访问后再打开浏览器。
5. 启动失败时显示中文错误提示，并告知用户检查 Node.js 与项目目录。

## 桌面体验

- 双击快捷方式即可使用。
- 启动过程中不长期显示命令行窗口。
- 快捷方式优先复用网站现有 `favicon.svg`；若 Windows 快捷方式不能稳定读取 SVG，则使用系统默认应用图标。
- 重复双击不会重复创建多个网站服务。

## 变更范围

- 新增一个 PowerShell 启动脚本。
- 在当前 Windows 用户桌面创建一个 `.lnk` 快捷方式。
- 不修改排盘算法、知识库、页面结构、复盘数据或网站端口配置。

## 验收标准

- 桌面可见“奇门遁甲”快捷方式。
- 网站未运行时，双击后能自动启动并打开首页。
- 网站已运行时，双击后能直接打开首页。
- 启动器不会弹出持续驻留的黑色命令窗口。
- 网站的构建、算法校验与知识校验不受影响。
