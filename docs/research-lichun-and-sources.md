# 立春边界与资料筛选记录

## 年柱回归

时家排盘四柱年柱采用立春精确交节时刻；日柱沿用原有 23 时换日口径。香港天文台 2024 年年历列出立春为香港时间 2 月 4 日 16:27（分钟精度）：https://www.hko.gov.hk/tc/gts/astron2024/files/HKO_almanac_2024.pdf 。测试取北京时间 16:26、16:28，分别检查年柱与月柱。`TZ=Asia/Shanghai npm run verify:qimen`；这个脚本使用宿主系统本地时间，现阶段不保证其他时区的结果。
