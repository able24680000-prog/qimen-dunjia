# 奇门首页 v2 · 宣纸日影盘

这是独立于旧 `prototype` 的 v2 预览小样。旧版九宫卡片页只作为数据结构参考，本版按 `docs/AGENTS.md` 与 `prompts/02-启动Prompt-流转光影版.md` 的审美方向重做。

## 打开方式

直接双击 `index.html`，或在本目录启动本地静态服务后访问。

## 本版动效

- 洛书轨迹：光点按 `4→9→2→7→6→1→8→3` 缓慢流动，24 秒一轮。
- 指针流转：指针随当前落宫微转，不做整盘 360 度旋转。
- 自然光扫纸：斜向光在书页与盘面上慢扫，周期 22 秒。
- 落宫高光：当前宫位柔和亮起，与洛书光点同步。

## v2.1 优化

- 新增 `tokens.css`，把纸色、墨色、朱砂、线色、光影和动效周期独立成设计 Token。
- 强化日影盘结构，增加盘沿、方位字、方位点、子午卯酉线和更清晰的盘面投影。
- 移动端压缩题字与版心间距，让首屏更接近一张完整海报。

## 设计取向

- 默认宣纸浅色。
- 红色只作点睛。
- 不做五行图例、卡片、粗 tooltip、暗色科技背景。
- 数据轻量化，只让宫位结构服务于“转”和“光”。
