# 任务目标（第一阶段 MVP）
只做一个东西：**一个会流转、有光影变化的九宫罗盘动效**，纯前端，
打开浏览器就能看，不依赖后端。

要求：
- 天圆地方结构（方框 + 圆罗盘 + 九宫）

- 光影在"变化"（见下方动效定义）
- 极简、留白、克制、不像 AI 模板、不像算命网站
- 宣纸底色为主（可加暗色模式切换，但默认是宣纸）

# 核心动效（你这次的主战场）

## A. 九宫流转（能量在九宫间转移）
选 1-2 种实现（不要全做，选最有"转"感的）：
1. **指针流转**：中心细长指针缓慢旋转/或在不同方位间游走，
   所指宫位最"亮/活"，其他宫渐暗。红点随指针移动。
2. **星移宫换**：九星（或光点）沿九宫循环移位，像星在宫位间流转。
3. **洛书轨迹**：能量光点沿洛书数字轨迹（4→9→2→7→6→1→8→3→4...）
   在九宫间流动，留下拖尾。
4. **五行流转**：五行色（木火土金水）在九宫间按生克顺序流转，
   宫位颜色随流转变化。

## B. 光影变化（光在盘面行走）
选 1-2 种实现：
1. **自然光扫过**：一束斜光在盘面缓慢扫过，被照到的宫位变亮、
   阴影区变暗，形成明暗韵律（像阳光照在纸上）。
2. **落宫高光**：指针/用神所指宫位有柔和高光，向外渐暗（呼吸式）。
3. **全局呼吸**：整个盘面光影缓慢明暗呼吸（周期 8-15 秒，克制）。
4. **刻度流光**：外圈罗盘刻度上有光点沿圆周流动（像钟表走字）。

> 关键：动效要"慢、柔、有呼吸感"。周期低于 4 秒会显廉价。
> 流转和光影要"有关联"——比如指针指到哪，哪就亮，光随指针走。

# 数据层（轻量，不要抢戏）

- 中央值符位

# 审美方向（Taste-Skill 注入，必须守）
- **气质**：天圆地方罗盘 + 东方极简 + 工程图纸 + 禅意。不是功能网页。
- **底色**：宣纸感（浅米白 #f7f3ed 一类），带极淡纸纹/光影。
- **线条**：细线（1px 级）、低对比、克制。方框/圆圈/刻度都细。
- **用色**：90% 是墨色线条 + 宣纸底。红色只点睛（印章/用神红点），
  五行色只在流转时光晕里出现，平时不显。
- **字体**：标题用书法/楷体竖排；标注用小号无衬线，像图纸注记。
- **留白**：大量。盘面占视觉中心，四周留白。
- **禁用**：大红大金、云雾背景图、龙纹、太极堆砌、霓虹、emoji、

# 验收标准（必须全部满足）
1. 浏览器打开，能看到天圆地方罗盘结构（方+圆+九宫），气质对标参考图

3. 能看到"光影在变化"（盘面有明暗流动/呼吸，不是死亮）
4. 红色只出现在用神点和印章，克制
5. 整体"安静、有呼吸感、高级"，不像 AI 模板、不像算命网站
6. console 无 error
7. 移动端（375×667）九宫仍可读、动效不卡

# 动效专项验收（Vision 审查时必须逐条看，这是"顶级"的门槛）
- **节奏**：所有动效周期 ≥ 4 秒，无眩晕感；全局呼吸类 8-15 秒
- **缓动**：运动用 ease-in-out / cubic-bezier，不用 linear 生硬匀速
- **拖尾/过渡**：流转光点有拖尾或渐隐，不是硬切
- **光影自然度**：明暗变化像"光真的在走"，不是生硬 opacity 跳变；
  用叠加混合（screen/overlay）或径向渐变模拟，不用纯色块
- **静止也美**：动效暂停的瞬间，画面依然是一张好图（不是靠动才好看）
- **关联**：流转与光影联动（指针指到哪，哪亮，光随指针走）
- **性能**：60fps，不动 width/height/top/left，只用 transform/opacity
- **对比度**：动效最暗时文字仍可辨（≥ 4.5:1）
