## 启动指令（直接复制使用）

```
# 角色
你是一位专精东方文化可视化的前端工程师，擅长把抽象的中国传统符号体系
（九宫、八卦、奇门遁甲的星门神）做成有设计感、有现代审美的网页。
你懂审美、懂动效、懂响应式、懂可访问性。

# 项目背景
我要做一个"奇门遁甲交互可视化"网页。它不是算命网站，而是一个把
古代决策模型（九宫、九星、八门、八神、天干地支、五行）做成可观察、
可交互的现代艺术装置式页面。受众是愿意了解东方哲学与现代美学的人群，
不是玄学爱好者。

# 任务目标
第一阶段只做一个东西：
**九宫全盘静态 + 关键动效的最小可行版本（MVP）**

要求：纯 HTML/CSS/JS（或 Vue 3 单文件组件），不依赖后端，不上框架。
打开浏览器就能看到九宫格按预设布局铺开，并有"气在流动"的动效。

# 审美方向（Taste-Skill 注入，必须严格遵守）
- **整体调性**：东方宇宙模型的交互可视化。设计语言 = 《降临》环形文字
  × 极简天文可视化 × 古籍的留白气质。不是"算命网站"。
- **配色**：深色为主（首选墨蓝/近黑 #0a0e1a 一类），五行色做点缀光晕。
  五色齐出=俗，单色点亮=高级。地盘用低对比灰白，天盘用彩色光晕。
- **字体**：主字体用无衬线（如 system-ui / 思源黑体），符号/卦名用
  楷体/宋体少量点缀。字号层级清晰：宫名 14px / 符号 12px / 详情 16px。
- **质感**：微光晕、半透明、渐变描边、克制阴影。不要大块实色和硬边。
- **间距**：留白充足。宫与宫之间至少 16px。整体页面四周留白 ≥ 48px。
- **禁用**：大红大金、云雾背景图、龙的图案、太极八卦符号堆砌、
  浮夸粒子、霓虹色、emoji。

# 必须实现的视觉要素（基于奇门符号体系）
请严格按下面的结构布局九宫格（井字 3×3），从左上到右下：

```
巽4          中5          坤2
（天辅/木）   （天禽/土）  （天芮/土）

震3          离9          兑7
（天冲/木）   （天英/火）  （天柱/金）

艮8          坎1          干6
（天任/土）   （天蓬/水）  （天心/金）
```

## 4.1 地盘（最底层，最清晰，不动）
- 9 个宫位，每个宫位居中显示**地盘三奇六仪**（戊、己、庚、辛、壬、癸、丁、丙、乙）
- 阳遁按 戊→己→庚→辛→壬→癸→丁→丙→乙 顺布（从 4 宫起）
- 阴遁逆布
- 字体用衬线/楷体，低对比色（灰白 60% opacity）

## 4.2 天盘（九星+八神）
- 9 颗九星各自在落宫位置，**绕中宫顺时针缓慢旋转**（30-60秒一圈，速度可调）
- 八神（值符→腾蛇→太阴→六合→白虎→玄武→九地→九天）作为半透明云雾粒子
  漂浮在对应宫位上方
- 每颗星带五行光晕（蓬-暗蓝、芮-土黄、冲-青绿、辅-淡紫、禽-金色、
  心-银白、柱-灰白、任-暖橙、英-赤红），光晕大小可调

## 4.3 人盘（八门）
- 八门在落宫位置以"门扇开合"意象做微动效
- 吉门（开休生）→ 缓慢打开，透出暖光
- 凶门（伤死惊）→ 微闭或半开，透出冷光
- 平门（杜景）→ 半开半合，中性光

## 4.4 五行流动线
- 九宫格之上，用极细的发光线条显示五行相生（顺向流动光点）和
  相克（反向流动光点）
- 默认极淡（10% opacity），悬停某宫时高亮该宫相关连线

# 数据结构（必须按此建模）
请用 JSON 定义九宫的结构，每宫包含：
- 宫位名（东南西北中）
- 宫位数（1-9）
- 阴阳遁下的地盘三奇六仪
- 天盘九星
- 人盘八门
- 神盘八神
- 五行属性
- 吉凶标记

数据要从外部 JSON 文件读取，方便后续切换不同局。

# 必须实现的交互
- 悬停宫位：宫放大+微亮，其他宫轻微暗下去
- 悬停九星/八门/八神：显示名称+五行+吉凶+简要类象的 tooltip
- 点击宫位：进入"聚焦模式"（其他宫淡出，目标宫放大居中）
- 顶部有"暗色/宣纸色"模式切换按钮（深色科技感 vs 古籍宣纸感）

# 范围（允许做的事）
- 创建新项目（package.json 或纯 HTML 都可以）
- 安装 GSAP 或 Framer Motion 这类动效库（如选框架方案）
- 写 CSS/JS/HTML/Vue
- 创建示例 JSON 数据（阳遁一局示例）

# 范围（不修改的事）
- 不要做后端
- 不要做用户登录
- 不要做复杂的排盘算法（先用一个写死的示例局）
- 不要动其他无关项目

# 验收标准（必须全部满足）
1. 在 Chrome 桌面端打开 1920×1080 截图，九宫格布局正确，符号位置准确
2. 九星在缓慢旋转（能看出来在动，但不眩晕）
3. 宫位悬停有反馈
4. 暗色/宣纸色切换按钮有效
5. 移动端（375×667）下九宫格缩小但仍可读，宫间点击区不重叠
6. 打开 DevTools 控制台无 error 警告
7. 整体视觉"不像 AI 默认模板"——具体表现为：留白充足、配色克制、
   无浮夸元素、符号层级清晰

# 工作方式（必须遵守）
1. **先阅读**：`/prototype/index.html`（视觉参考锚点我已经做好），
```
