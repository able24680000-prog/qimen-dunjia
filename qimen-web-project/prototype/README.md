# 奇门遁甲交互可视化网页 · 视觉参考原型

> 这是用最小成本搭的视觉锚点，用来让 Codex 和你（阿未）对齐审美方向。
> **不是产品级代码**——Codex 需要在它的基础上审美升级、逻辑完善。

## 怎么打开

### 方式 1：直接打开
双击 `index.html` 即可在浏览器中查看（部分浏览器对本地文件有限制，可能需要方式 2）。

### 方式 2：本地启动（推荐）
```bash
cd prototype
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 这个原型包含什么

✅ **已实现**：
- 暗色 / 宣纸色双模式切换（右上角按钮）
- 3×3 九宫格布局（含中宫）
- 地盘天干（戊己庚辛壬癸丁丙乙）
- 天盘九星（带五行光晕）
- 人盘八门（吉门暖光、凶门冷光、平门中性光）
- 神盘八神（半透明光晕漂浮）
- 宫位呼吸光晕动效
- 宫位悬停 tooltip（显示吉凶+类象）
- 移动端响应式
- 配色用 CSS 变量
- `prefers-reduced-motion` 支持

❌ **未实现**（留给 Codex）：
- 九星绕中宫旋转（目前是各星在宫内脉动）
- 五行流动线（目前是静态渐变）
- 点击进入"聚焦模式"
- 真实排盘算法（目前是写死的阳遁一局）
- 完整键盘可访问性
- Playwright 自动化截屏对比

## 配色系统（重点参考）

所有颜色定义在 `style.css` 顶部 `:root`，切换主题只需改 CSS 变量。

```css
/* 暗色（科技感） */
--bg-primary: #0a0e1a
--text-primary: rgba(232, 232, 240, 0.95)
--wuxing-mu: #5fa777   /* 木 */
--wuxing-huo: #d96f4e  /* 火 */
--wuxing-tu: #c8a96a   /* 土 */
--wuxing-jin: #c4c4d4  /* 金 */
--wuxing-shui: #5d7ba8 /* 水 */

/* 宣纸（古籍感） */
[data-theme="paper"] {
  --bg-primary: #f7f3ed
  ...
}
```

## 关键动效参数

| 动效 | 时长 | 实现 |
|------|------|------|
| 宫位呼吸 | 4 秒 | `animation: gongBreath` |
| 九星光晕 | 4 秒 | `animation: starPulse` |
| 八门开合 | 5 秒 | `animation: doorBreath` |
| 八神漂浮 | 10 秒 | `animation: shenFloat` |
| 背景微光 | 20 秒 | `animation: bgBreath` |

## 数据结构（用于后续扩展）

`data.js` 中 `BUREAU_DATA` 对象定义了完整的局数据：
- `meta`：局的基本信息（阴阳遁、局数）
- `palaces`：9 个宫位的数据（地盘/天盘/人盘/神盘）
- `wuxing`：五行颜色映射
- `doorGlow`：八门吉凶光晕映射
- `shenGlow`：八神光晕映射

**后续扩展**：换局只需替换 `palaces` 数组，无需改渲染代码。

## 给 Codex 的开发建议

1. **保留**这套配色变量系统（`--bg-primary`、`--wuxing-*` 等）
2. **保留**数据与代码分离的设计
3. **升级**到 Vue 3 或纯模块化 JS（更易维护）
4. **添加**完整九星绕中宫旋转的动效
5. **添加**真实排盘算法（用 JS 实现阳盘/阴盘起局）
6. **添加**Playwright 截屏对比测试
