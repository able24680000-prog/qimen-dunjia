# 原型修改指南 · 给阿未（不用懂前端，照着改就行）

> 这份指南是写给"想动原型、但不一定写代码"的人看的。
> 每一节都有「改什么 → 改哪里 → 怎么改 → 改完看哪里」四步。
>
> **改之前先看完整个流程**，避免改完发现没效果或改坏。

---

## 🛠️ 准备工作（30 秒）

### Step 1 · 把包下到本地
把 `qimen-web-project.zip` 下到你能找到的位置（桌面或文档），右键 → 解压。

### Step 2 · 启动本地服务
打开终端（Mac：终端 / Windows：PowerShell），进入 prototype 目录：

```bash
cd 你的解压路径/qimen-web-project/prototype
python3 -m http.server 8000
```

看到 `Serving HTTP on 0.0.0.0 port 8000` 就成功了。

> **没装 Python？** 两种办法：
> 1. 装一个：Mac 自带不用装，Windows 去 [python.org](https://www.python.org) 下载
> 2. 用 VS Code 装个 `Live Server` 插件，一键启动

### Step 3 · 浏览器打开
地址栏输入：`http://localhost:8000`
看到九宫格就对了。

### Step 4 · 改完怎么生效
- 改 `style.css` / `script.js` / `data.js` → 浏览器**强制刷新**（Mac: `Cmd+Shift+R` / Windows: `Ctrl+Shift+R`）
- 改 `index.html` → 直接刷新即可

## 🎨 改什么 → 改哪里（速查表）

下面是**最容易想改的 6 类东西**的对应文件位置。所有"行号"是大概位置，用 VS Code / Cursor 打开文件后搜关键词能更快找到。

### 一、改配色（最常改）

**改这里**：`prototype/style.css` 顶部的 `:root` 块

| 你想改的 | 找这个变量 | 现在的值 | 注释 |
|---------|-----------|---------|------|
| 主背景（暗） | `--bg-primary` | `#0a0e1a` | 深色科技感的底色 |
| 主背景（宣纸） | `--bg-paper` | `#f7f3ed` | 古籍宣纸的底色 |
| 主文字色 | `--text-primary` | `rgba(232, 232, 240, 0.95)` | 接近白色 |
| 次文字色 | `--text-secondary` | `rgba(200, 200, 215, 0.7)` | 灰白 |
| 地盘符号色 | `--text-dipan` | `rgba(180, 180, 200, 0.45)` | 最淡的颜色 |
| 木的颜色 | `--wuxing-mu` | `#5fa777` | 青绿 |
| 火的颜色 | `--wuxing-huo` | `#d96f4e` | 赤红 |
| 土的颜色 | `--wuxing-tu` | `#c8a96a` | 土黄 |
| 金的颜色 | `--wuxing-jin` | `#c4c4d4` | 银白 |
| 水的颜色 | `--wuxing-shui` | `#5d7ba8` | 暗蓝 |
| 吉门光晕 | `--glow-good` | `rgba(217, 175, 110, 0.4)` | 暖色 |
| 凶门光晕 | `--glow-bad` | `rgba(120, 140, 180, 0.3)` | 冷色 |

**改宣纸模式下的配色**：找 `[data-theme="paper"]` 块，里面是宣纸模式专用的变量。

**改的方法**：
```css
/* 比如想让暗色背景更黑 */
--bg-primary: #000000;  /* 改成纯黑 */

/* 比如想让木的颜色更鲜亮 */
--wuxing-mu: #4ade80;  /* 改成更鲜亮的绿 */
```

保存 → 浏览器强制刷新 → 立刻看到效果。

### 二、改动效速度（第二常改）

**改这里**：`prototype/style.css` 顶部的「动效参数」区

| 动效 | 变量 | 现在的值 | 含义 |
|------|------|---------|------|
| 九星光晕呼吸 | `--anim-glow-pulse` | `4s` | 改大=变慢更克制 |
| 八门开合周期 | `--anim-door-cycle` | `5s` | 改大=更慢更稳重 |
| 神盘云雾漂浮 | `--anim-shen-float` | `10s` | 改大=更慢更安静 |
| 悬停过渡 | `--anim-hover` | `0.4s` | 改小=更敏捷 |

**改的方法**：
```css
/* 比如想让九星呼吸更慢更克制 */
--anim-glow-pulse: 6s;  /* 从 4s 改成 6s */
```

**经验值**：
- 太晃眼 → 把所有秒数翻倍
- 想要点生命力 → 减 30%
- 想要"博物馆感" → 所有动效都改成 8s 以上

### 三、改文字内容（第三常改）

#### 改宫位名称 / 方位
**改这里**：`prototype/data.js` → `palaces` 数组

比如想改"巽"为"东南"：
```javascript
{
  id: 4,
  pos: { row: 0, col: 0 },
  name: "东南",  // 改这里
  direction: "",   // 这里改空
  ...
}
```

#### 改九星 / 八门 / 八神名称
直接改 `tianpan` / `renpan` / `shenpan` 字段。

比如把"天蓬"简化为"蓬"：
```javascript
tianpan: "蓬",  // 改这里
```

#### 改类象说明（悬停时显示）
直接改 `leiXiang` 字段。

比如"巽"的类象想改成更现代的描述：
```javascript
leiXiang: "风/沟通/文化传播/品牌建设"  // 改这里
```

## 🚨 常见错误

### "我改了没生效"
- **CSS 改完没强刷**：Cmd+Shift+R / Ctrl+Shift+R
- **改错了文件**：确认改的是 `prototype/style.css` 不是 `docs/AGENTS.md`
- **语法错**：少了个分号 `;` 或大括号 `}`，看 Console 报错

### "我改坏了，回到原样"
- 删掉解压的文件夹，重新解压 zip 就行

### "我想改但不知道改哪个变量"
- 用 VS Code / Cursor 打开 `style.css`
- 顶部就是所有变量，一目了然
- 鼠标悬停在颜色值上能预览

## 💡 工作建议

**改的顺序**：
1. 先调**配色**（最容易出效果，1-2 分钟看到）
2. 再调**动效速度**（气质立刻变）
3. 再调**文字内容**（让类象更贴你公众号调性）
4. 最后调**布局**（最复杂，先不动）

**改完一批后再开 Codex**：
- 一次改 5-10 处配色/动效，刷新看效果
- 觉得"对了"再让 Codex 来
- 改的每一处都在 `AGENTS.md` 里记一下（最后我会帮你整理成规则）

**小技巧**：
- 用 [coolors.co](https://coolors.co) 在线生成配色，复制 hex 值替换
- 用 [type-scale.com](https://type-scale.com) 调字号比例
- 改完一组颜色后截屏保留，方便对比
