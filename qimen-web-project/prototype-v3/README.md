# 奇门首页 v3 · 宋版活盘

独立于 v2 的首页原型。视觉采用“书七仪三”：宋版书页秩序为主，日影仪器为辅。

## 预览

从项目根目录启动静态服务后访问：

```text
http://127.0.0.1:4173/prototype-v3/
```

## 动效

- 纸面显现：0–0.8 秒
- 版框落墨：0.8–1.8 秒
- 地盘归位：1.8–3.2 秒
- 门星入盘：3.2–4.8 秒
- 罗盘校准：4.8–6.2 秒
- 朱砂定印：6.2–7.2 秒

动画只播放一次，结束后保持静止。页面提供“重演”命令，并支持 `prefers-reduced-motion`。

盘面不再使用时针或晷针。外层刻度、方位与朱砂校准点组成罗盘圈，以小角度旋转完成归零；九宫正文保持静止。

## 数据

示例局位于 `data/bureau.json`，包含局式、值符、值使及九宫的地盘、八门、九星、八神信息。

本版采用八门本位示例：开门乾六、休门坎一、生门艮八、伤门震三、杜门巽四、景门离九、死门坤二、惊门兑七。
