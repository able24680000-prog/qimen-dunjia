## 结果

通过。页面已形成“书七仪三”的宋版活盘：首页结构以半叶、版框、界行和白口为主，仪器结构只承担读盘与校时，不再表现为科技装饰。

## 已修问题

- P1：首轮浏览器截图中 Canvas 盘沿过弱。补充可缩放的结构盘沿，并保留 Canvas 刻度，俯视仪器结构现在清晰稳定。
- P1：旧版手机首屏看不到完整盘面。重新安排移动端题签、盘面和入口，375 x 667 下主要内容完整可见。
- P2：移动端纸面光与书耳造成横向溢出。限制版心裁切范围并将书耳收回版框内。
- P2：桌面首屏存在纵向滚动。调整首屏网格高度，1280 x 720 下页面与视口等高。
- P2：旧动效循环跳宫且缺少因果。改为 7.2 秒一次性“校时归位”，结束后完全静止。

## 可接受差异

- P3：网页盘沿比静态基准略强。这是为了保证九宫四层信息与仪器刻度在真实屏幕上的可读性。
- P3：网页纸纤维比概念稿更真实，但对比度已控制在正文以下，不影响阅读。

## 九宫文字复核（2026-07-15）

- 修改前：宫数位于左上，卦名位于右上，四层信息集中在宫格底部，视觉重心偏斜且近似数据表。
- 修改后：宫数固定居中，卦名位于上中；天干、八神、九星、八门分置四角，值符红点贴近宫数。
- 桌面与 375 x 667 手机尺寸均未检测到文字包围框相互碰撞，也没有横向溢出。
- 对照截图：`qa-type-before.png`、`qa-type-after.png`、`qa-type-mobile.png`。

## 功能检查

- 重演按钮可重新播放一次完整开场。
- 鼠标、键盘和触摸选择宫位后，右侧局注同步更新。
- `prefers-reduced-motion` 直接进入完成态；页面另提供 `?static=1` 供视觉验收。
- 数据从独立 JSON 读取，控制台无错误，脚本与 JSON 语法检查通过。

## 罗盘与八门复核（2026-07-15）

- 已删除时针和影针，DOM 中不再存在 `.gnomon` 或 `.gnomon-shadow`。
- 外层刻度、方位和朱砂校准点合并为罗盘圈，开场以 `-12° → -4° → 0°` 小角度归位，结束后静止。
- 八门本位已校正：乾六开门、兑七惊门；九星同步校正为乾六天心、兑七天柱。
- 值符与值使迁至乾六宫，右侧局注保持“天心星、开门”一致。
- 最终静帧：`qa-compass-final.png`；旋转阶段：`qa-compass-motion.png`。
