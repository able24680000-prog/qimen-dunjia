# 事件断局与截图核对

## 先明确当前问项

事件入口接收起局时间、事项大类、问句与可观察结果。可补阶段、期限、各角色、行动先后和急缓。先看程序识别出的问项，必要时用 `topic` 指定。多问用同一盘分别分析。问项不明确时，通用用神只供初步定位；同时命中多个细项、主问待核时，先收住应期。

| 问项代码 | 主用神 | 合参 |
|---|---|---|
| 求职签约 | 开门 | 值符、日干、时干；以值使核签批或执行 |
| 职称评审 | 天辅 | 日干、时干、值符；核评审程序 |
| 职位晋升 | 开门 | 年干、值符与日干 |
| 旧款回收 | 伤门 | 按讨债条目合参天乙、时干、值使。天乙须先按采用的口径确认落宫，程序未定位时保留待核 |
| 新项目盈利 | 生门 | 戊代表资本，核项目结算与实际成本 |
| 借贷 | 值使 | 值符代表另一关键环节，观察审批与实际放款 |
| 人员走失 | 六合 | 时干与寻找者合参；杜门、伤门、庚作辅助 |
| 宠物走失 | 时干 | 六合备验，记录约定的实际观察结果 |
| 物品遗失 | 时干 | 杜门、庚作辅助，标明此前最后确认的位置 |
| 感情复合 | 六合 | 乙、庚、休门、日干；按问者性别分乙庚主次 |
| 婚嫁成事 | 休门 | 乙、庚、六合、日干；休门主嫁娶 |
| 疾病转归 | 天芮 | 日干、乙(医药)、天心(医生)、死门；仅取象不作诊断 |
| 求医问药 | 天心 | 天芮、乙、日干、死门；服从医嘱 |
| 诉讼胜负 | 开门 | 值符(原告)、庚(被告)、惊门、日干；开门为法官 |
| 纠纷调解 | 六合 | 开门、值符、日干、时干；六合主谈判 |
| 出行安危 | 日干 | 时干、九天、九地、开门 |
| 迁移搬家 | 开门 | 日干、时干、九天、九地 |
| 开业择日 | 时干 | 日干、开门、生门、值符；时干为所择之日 |
| 婚嫁择日 | 时干 | 日干、休门、六合、乙、庚 |
| 晴雨判断 | 天英 | 天蓬、天柱、壬、癸；天英主晴、天蓬天柱主雨，实际以气象预报为准 |
| 风雨判断 | 天辅 | 天英、天蓬、天柱；天辅主风 |
| 阳宅吉凶 | 生门 | 日干、时干、死门；须结合实际坐向堪舆 |
| 阴宅吉凶 | 死门 | 日干、时干、生门；不作吉凶恐吓，须由专业人士勘定 |

`topic` 是上表首列或“通用”。其他大类沿用包内分类。必要时用 `primary` 从本问已列用神中指定主用神，输出注明依据。旧项目审批、确认付款日、实际进账是不同的观察结果，一次主判断只对一个节点负责。

```python
from workflow import event
from analyze import format_package

answer = event('2026-07-01 02:10', '求财', '旧项目尾款何时进账', '实收尾款',
               city='上海', topic='旧款回收', horizon='7月31日前',
               roles={'问者':'本人','所测人':'本人','对方':'付款方'},
               first_mover='本人', urgency='缓', stage='待付款审批')
print(answer['盘头'])
print(format_package(answer['分析']))
```

动静按已发生的先后定位，先动为客、后动为主。例中的“本人”在代问场景按 `roles['所测人']` 解释，所以代问时要明确行动指的是谁。程序展示主客及优先读取的宫内证据，后续再判断该条件如何影响同一张盘。急问先看神，缓问先看门与值使，仍须合参格局和现实条件。代问先标清问者及日干归属，所测者、对方各自的用神与年命另核，报告注明年命属于谁。

值使过程先看门宫关系、月令、旬空，再看与日干及主用神的关系。分写结果倾向和过程条件。依据冲突时说明哪条限制关系到实际节点，保留同向和反向证据，避免同宫重复计权。

## 应期按所问结果取证

先定什么事件算兑现，再选与本问相关的填实、冲实、冲墓或马动线索。墓库注明基础干墓与三奇入墓来源。丁落艮、乙落乾可出现三奇入墓候选；是否入墓或入库仍按当令强弱和事项条件复核。冲支按盘中对应地支计算。伏吟反吟先说明节奏。通用取数可供传统规则研习，事件入口不自动推导具体日期。

“观察期限”是问者设定的核验范围。结合现实节点在范围内选候选，写清触发条件与失效条件。无直接证据时说清待核原因。事后反馈使用案例记录保留原断，延期兑现也保留原期限。数据包 `yingqi.期限锚定` 会提示期限与候选的四种配合状态；入口未给 `horizon` 时会返回「期限提示」引导补齐，但不会阻断起局，也不自动推导具体日期。

## 截图转录

看图时将清楚辨认的字段转成字典，未读项留空或写 `None`；确认不存在的星门神用空字符串，确认没有天盘干用空列表。空亡、马星标记用 `True` 或 `False`。以下结构是录入示意，四柱按年月日时填写；星如显示天芮天禽同宫，统一转写“芮禽”。地盘主干、寄干按图上顺序转录。附注中另写图的流派、时间与时区、真太阳时及换日设置、旬空口径。

```python
image_rows = {
    '盘头': {'四柱': ['丙午','甲午','丙子','己丑'], '局式': '阴六局',
           '旬首': '甲申', '旬空地支': ['午','未'],
           '值符': ['天辅','坤2'], '值使': ['杜门','艮8']},
    '九宫': {'坤2': {'天盘':['庚'], '地盘':['壬','己'], '门':'开门',
                 '星':None, '神':'值符', '空':True, '马':False}},
}
result = event('2026-07-01 02:10', '事业官运', '何时签约', '双方完成签章',
               city='上海', screenshot=image_rows)
print(result['截图核对'])
```

结果列出一致、待辨和冲突字段。两套盘若有差异，报告哪一宫哪一项不一致、影响哪些用神及结论；暂停自动综合，人工可以先使用截图中清楚且足以支持的部分。只有截图时可用 `stamp=None` 管理转录与待辨项。完整截图与引擎一致时，才沿用自动分析。截图转录与合参规则亦用于复核已有终身盘。

数据包 `tendency` 给出确定性成败倾向（成/败/两可＋信心＋得分＋证据链），`format_package` 以【成败倾向结论】置顶。它是断语的可核验基线，不是最终裁决：救应、代测关系、现实节点仍须按本报告流程复核，不得直接套用。健康类以天芮为主用神时评分反向（病星休囚为有利）。
