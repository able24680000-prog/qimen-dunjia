# 转宫法——多条件分支预测

> 来源：神兵奇门体系（《奇门遁甲笔记151页》）。转宫法解决的核心问题：**同一盘面，不同条件 → 不同结论**。不用它只能回答"吉不吉"，用它才能回答"跟谁吉、在哪吉、什么时候吉"。

---

## 一、核心原理

### 1.1 双局机制

| 局类型 | 功能 | 分析方式 |
|--------|------|---------|
| **时间局** | 反映当下状态、信息层面的吉凶 | 固定宫位分析——用神落哪宫看哪宫 |
| **事实局** | 求测未来的客观结果 | **转宫分析**——把用神按条件飞到目标宫位 |

> 时间局的结论 ≠ 未来的结果。两者矛盾时，以事实局为准。

### 1.2 转宫操作

时间局中，用神落在某宫时，附带四个伴随符号。转宫时**全部同步移动到目标宫位**：

| 要素 | 伴随符号 | 转到目标宫后 | 
|------|---------|------------|
| 用神（八门） | — | **碰到**目标宫原始八门 → 判断成败 |
| 九星 | 与用神同宫的九星 | **碰到**目标宫原始九星 → 判断后续连带事件 |
| 八神 | 与用神同宫的八神 | **碰到**目标宫原始八神 → 判断潜在变化因素 |
| 奇仪 | 与用神同宫的奇仪 | **碰到**目标宫原始奇仪 → 判断环境细节 |

### 1.3 五行生克——谁说了算

飞到的一方为**主**，碰到的一方为**客**：

| 生克 | 谁说了算 | 含义 |
|------|---------|------|
| 主生客 | 客 | 目标条件的影响力显现 |
| 主克客 | 主 | 用神自身的属性显现 |
| 客生主 | 主 | 用神自身的属性显现 |
| 客克主 | 客 | 目标条件的影响力显现 |
| 比和 | 双方 | 两者属性都显现 |

## 二、五种触发条件

### 2.1 时间条件

| 条件 | 转宫目标 | 用途 |
|------|---------|------|
| 某年 | 年干落宫 | 问"哪年做"——把用神飞到目标年干落宫 |
| 某月 | 月干落宫 | 问"哪月做" |
| 某日 | 日干落宫 | 问"哪天做" |
| 某时 | 时干落宫 | 问"什么时辰做" |

**时间粒度选择**：长期决策看年干，中期看月干，短期看日干/时干。

### 2.2 方位条件

| 条件 | 转宫目标 | 
|------|---------|
| 去某方位 | 目标方位对应的九宫 |
| 八大方位的干支 | 对应地支宫位 |

### 2.3 人物条件——八门类象法

每个人物对应一个八门。把用神飞到该人物的落宫（或该人物出生年干落宫）：

| 人物 | 对应用神 | 
|------|---------|
| 领导/上级 | 开门 |
| 兄弟姐妹/朋友 | 休门 |
| 父母 | 生门 |
| 子女 | 伤门 |
| 配偶/情人 | 杜门 |
| 部下/手下 | 景门 |
| 对方/对手/敌人 | 死门 |
| 长辈（非父母） | 惊门 |

### 2.4 环境条件——八卦类象法

| 环境 | 对应宫位 | 
|------|---------|
| 大城市/首都/高档场所 | 乾6 |
| 乡村/田野/会场 | 坤2 |
| 山区/仓库/坟地 | 艮8 |
| 平原/园林/管道 | 巽4 |
| 闹市/机场/大道 | 震3 |
| 娱乐场/沼泽/废墟 | 兑7 |
| 学校/图书馆/火电厂 | 离9 |
| 江河/酒店/地下室 | 坎1 |

### 2.5 性质条件——八门类象法

按所做事务的性质对应八门，把用神飞到该门原始宫位：

| 事务性质 | 对应宫位 |
|---------|---------|
| 化工/电力/机械/政府项目 | 乾6（开门） |
| 房地产/美容/旅游/家庭服务 | 坎1（休门） |
| 动物/医疗/洗浴/种植养殖 | 艮8（生门） |
| 车辆/交通/物流/军警 | 震3（伤门） |
| 植物/保密/技术研发 | 巽4（杜门） |
| 美术/高科技/影视/餐饮 | 离9（景门） |
| 农业物资/殡葬/不动产 | 坤2（死门） |
| 食品/餐饮/法律/口才 | 兑7（惊门） |

## 三、转宫分析标准流程

### Step 1：时间局定调

先用张氏竖看+横看+内外盘+月令，判断用神落宫的基本吉凶。这一步确定**大方向**。

### Step 2：识别转宫条件

根据用户问题，提取需要对比的条件维度：
- 问"和谁合作"→ 人物条件
- 问"在哪里做"→ 方位或环境条件
- 问"什么时候做"→ 时间条件
- 问"做什么类型"→ 性质条件

### Step 3：逐条件转宫

对每个条件：
1. 确定目标宫位
2. 把用神（八门）飞到目标宫 → 看碰到什么门 → 按属性关联+五行生克判断成败
3. 伴随九星飞到目标宫 → 看碰到什么星 → 判断后续连带事件
4. 伴随八神飞到目标宫 → 看碰到什么神 → 判断潜在变化因素
5. 伴随奇仪飞到目标宫 → 看碰到什么仪 → 判断环境细节

### Step 4：多条件交叉对比

将所有条件的结果并列对比，给出最优选择。

## 四、分类预测转宫速查

### 4.1 求财（交易+开店）

| 用神 | 八门=生门（求测方）或惊门（对手方） |
|------|-----------------------------------|
| 时间条件 | 年干（长期）/ 时干（短期） |
| 方位条件 | 八大方位的干支落宫 |
| 人物条件 | 合伙人/对方年命落宫 |
| 环境条件 | 交易地点对应的环境宫 |

**判断要点**：
- 生门飞到目标宫碰开门/休门/生门 → 该条件下赚钱
- 生门飞到目标宫碰死门/惊门/伤门 → 该条件下赔本或有纠纷
- 生门飞到目标宫碰杜门 → 有波折坚持可获利
- 生门飞到目标宫碰景门 → 期望过高，实际利润低于预期
- 对方惊门飞到求测方宫碰生门 → 对方主动，对求测方有利

### 4.2 事业

| 用神 | 八门=开门（事业/单位） |
|------|---------------------|
| 时间条件 | 年干落宫 |
| 方位条件 | 目标城市/方向对应宫位 |
| 人物条件 | 领导（年干落宫）/ 同事（月干落宫） |

**判断要点**：
- 开门飞到目标宫碰生门/休门 → 该条件下事业顺利
- 开门飞到目标宫碰死门/惊门 → 该条件下事业受阻

### 4.3 出行

| 用神 | 八门=伤门 |
|------|----------|
| 时间条件 | 月干（一个月以上）/ 日干（一个月内）/ 时干（几天） |
| 方位条件 | 目的地对应宫位 |
| 人物条件 | 同行者对应宫位 |

### 4.4 婚姻

| 用神 | 八门=杜门 |
|------|----------|
| 人物条件 | 对方年干落宫 |
| 方位条件 | 对方所在方位 |

## 五、与张氏断局的关系

```
时间局（张氏竖看+横看）→ 回答"总体吉凶"
        ↓
    需要对比选项？
        ↓ 是
事实局（转宫法）→ 回答"哪个选项最吉"
        ↓
    克应局 → 锁定最终结果（如有匹配克应）
```

- 转宫法不替代张氏断局——它是在张氏定调之后的**条件精细化**
- 转宫后不同条件给的结论可能相反——这正是它的价值：帮用户**选最优条件**
- 如果用户没提供具体条件（只说"问个事"），只做时间局分析即可，不需要强制转宫

---

## 六、使用规则

1. **先时间局，后事实局**：永远先完成张氏断局分析，再根据用户是否有多选项需求决定是否转宫
2. **用神确定后再转**：必须先准确定位用神落宫及其伴随符号
3. **全部符号同步迁移**：用神的九星、八神、奇仪必须一起转
4. **五行生克决定权归属**：主客生克 → 谁说了算 → 该属性意义显现
5. **多条件全转**：有N个选项就转N次，逐一对比
6. **矛盾的边界（精确表述）**：
   - **有明确对比条件时**：该条件下的转宫结论优先于时间局的总体吉凶——转宫回答的是「选哪个」，总体吉凶仍以张氏断局为准
   - **无具体对比条件时**：**不得启用转宫法**，只做时间局分析；禁止用转宫法「翻案」时间局的结论
   - 转宫结论与时间局矛盾且无对比条件支撑时，以张氏断局为准，转宫结果仅作参考线索记录
