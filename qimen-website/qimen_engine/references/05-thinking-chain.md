# 断局思考链——从盘面到决策的推导路径

> 核心原则：**同一个符号，在不同场景下有不同取向。** 不要背"某格局=某结果"，要练"从场景出发推导符号含义"的能力。

---

## 五层思考链

```
第一层：定局 → 大局先于单宫，伏吟/反吟定基调
    ↓
第二层：定位 → 我在哪、事在哪、谁主谁客
    ↓
第三层：定象 → 符号在这个场景下是什么意思
    ↓
第四层：定势 → 生克旺衰决定力量方向
    ↓
第五层：定策 → 利主还是利客、能否换位、最优条件
```

---

## 第一层：定局——大局先于一切

不急着看日干宫，先看三件事：

| 检查项 | 问题 | 为什么先看 |
|--------|------|-----------|
| 伏吟/反吟 | 星门是否在本宫/对冲宫？ | 伏吟=慢、利主；反吟=快、易反复。**基调定了，单个宫位的好坏事都在这基调里运行** |
| 天显时格 | 六甲时值符透出？ | 伴星伏吟时降为次要提示，可动条件由主用神复核 |
| 五不遇时 | 时干克日干并同阴阳？ | 依事项表评估阻力 |

**关键心态**：大局基调 > 单宫吉凶。大局伏吟+单宫吉=慢但成；大局反吟+单宫凶=反复败。

---

## 第二层：定位——找到自己在盘里的位置

| 定位 | 看什么 | 问什么 |
|------|--------|--------|
| 自己 | 日干落宫 | 我现在什么状态？能量如何？ |
| 事体 | 时干落宫 + 类别用神 | 事情本身什么状态？ |
| 主客 | 天盘为客、地盘为主 | **这场博弈中谁占主动？** |
| 内外 | 用神在内盘还是外盘 | 事近事远、快慢如何？ |

**主客是第二层最关键的判断**：伏吟偏静，反吟多变、九天利客、九地利主。主客关系直接决定后续策略方向。

---

## 第三层：定象——符号取向随场景变

**这是整个思考链的核心。** 同一个符号在不同场景中取向完全不同。

### 3.1 场景优先原则

拿到一个符号组合，先问"求测人问的是什么"，再决定怎么解读：

| 符号 | 婚姻场景 | 求财/谈判场景 | 健康场景 | 出行场景 |
|------|---------|-------------|---------|---------|
| 乙+辛（龙逃走） | 女方提离婚 | **策略性退让**、买方有筹码 | 病情好转/逃离病 | 出行可走 |
| 辛+乙（虎猖狂） | 男方提离婚 | 对方强势施压 | 病情恶化 | 不宜行 |
| 庚+戊（伏宫格） | 婚姻受阻 | 换地方换人可解 | 换医换药 | 换路线 |
| 天芮星 | （不常用） | 对方有弱点 | **核心病星** | — |
| 玄武 | 偷情暧昧 | **价格不透明**、有暗箱 | 病因不明 | 易迷路 |
| 九天 | 远嫁/异地 | **主动权在手**、可主导 | 病情向好 | 利远行 |
| 天心星 | 对方有心计 | **策略智慧**、算计 | 良医 | 路上遇贵人 |

### 3.2 取向翻转规则

符号本身无绝对吉凶——以下情况会翻转：

| 翻转条件 | 示例 |
|----------|------|
| 用神为天盘主动方 | 庚+戊：用神是庚→反吉（庚克戊，主动方得势） |
| 场景切换 | 龙逃走：婚姻=凶，谈判=吉（策略退让掌握主动） |
| 大局覆盖 | 伏吟复核延迟；反吟复核变化及转折条件 |
| 主客换位 | 门伏吟利主→买方主动变主→原本不利的龙逃走变成策略工具 |

### 3.3 符号取向判断三步走

```
① 确定场景类别 → 婚姻/求财/健康/事业/出行/官司？
② 确定用神身份 → 这个符号代表谁？是主动方还是被动方？
③ 确定大局基调 → 伏吟/反吟/天显时格？基调怎么影响这个符号？
```

## 第四层：定势——生克旺衰判力量

确定每个符号怎么解读之后，看到底谁压谁：

| 维度 | 看什么 | 判断 |
|------|--------|------|
| 生克方向 | 宫与宫之间的五行 | 生我/比和→有利；克我→不利 |
| 旺衰 | 用神在月令的状态 | 旺→力量大；衰→力量小 |
| 入墓/空亡 | 用神是否入墓或逢空 | 入墓→卡住（旺相约期=入库可救，衰败=真入墓）；空亡→虚、未定 |
| 门宫关系 | 八门与落宫的生克 | 门迫→受制；宫生门→得助 |

**定势的核心原则**：先看生克方向（定性），再看旺衰（定量）。生克决定"谁赢"，旺衰决定"赢得多大/多久"。

---

## 第五层：定策——从分析到行动

前四层看懂之后，最后一层是"怎么办"：

### 5.1 主客策略

| 大局 | 求测人身份 | 最优策略 |
|------|-----------|---------|
| 伏吟+利主 | 求测人是客 | **主客换位**——让对方向你靠拢 |
| 伏吟+利主 | 求测人是主 | 稳住、守住阵地、等对方动 |
| 反吟+利客 | 求测人是客 | 主动出击、快节奏 |
| 反吟+利客 | 求测人是主 | 设防、让对方先动暴露弱点 |
| 九天在身 | 求测人是客 | 主动方优势强 → 可主导谈判 |
| 九地在身 | 求测人是主 | 坚守有利 → 不妥协 |

### 5.2 主客换位策略（门伏吟场景）

门伏吟的核心困境：谁占主位谁占优，但主位固定不变。

**换位方法**：
1. **诱使对方动**：拒绝上门、要求对方来找你、设置对方必须回应的时间节点
2. **重新定义主场**：把交易/谈判地点改到自己熟悉的环境
3. **拖延+反向邀约**：拒绝当场决策，让对方后续主动跟进

主客换位成功后，门伏吟从"不利"变为"有利"——因为你变成了主。

### 5.3 转宫选最优

如果用户有多个选项（多个对象/时间/地点），用转宫法逐一对比，选生克最有利的那个。详见 `references/04-zhuangong.md`。

### 5.4 策略输出模板

```
【大局基调】：伏吟/反吟/平 → 利主/利客 → 总体节奏
【我的位置】：日干状态 → 当前能量 → 优势/劣势
【主客关系】：谁占主 → 策略方向
【关键信号】：最影响决策的1-2个符号 → 核心抓手
【行动建议】：基于上述推导的具体行动
【风险提示】：什么情况下策略失效
```

## 完整思考链示例——罗江普购房案

```
【第一层：定局】
八门伏吟 → 利主不利客 → 买方初始处于劣势
↓
【第二层：定位】
日干乙坎1(我)、生门艮8(房)、戊乾6(价)、时干癸巽4(事)
主客：售楼部为主，我为客
↓
【第三层：定象——场景=求财/谈判】
乙+辛(龙逃走) → 谈判场景=策略性退让，不是退缩
天心星 → 谈判场景=策略、算计、智慧
玄武在戊宫 → 价格不透明，有议价空间
时干癸+杜门+螣蛇 → 事有蹊跷，对方有隐瞒
↓
【第四层：定势】
戊入墓 → 价格卡住，资金被套
生门克日干(艮土克坎水) → 房子对求测人压力大
九天在生门 → 买方有主动权潜力
卯月生门囚 → 卖方春季能量不足
↓
【第五层：定策】
伏吟利主 → 必须主客换位！
龙逃走=策略退让 → "改天来我公司"→离开
天心星=策略 → 让销售顾问6天后上门
主客换位成功 → 买方变主
取数：开门乾6衰取4 + 戊乾6取6 = 4600
→ 10分钟签约
```

## 使用规则

1. **永远从第一层开始**：不先判断伏吟反吟就钻进单宫，是断局最常见的错误
2. **第三层是核心**：花最多时间在"这个符号在这个场景下是什么意思"
3. **不要跳过第五层**：断局不是终点，策略才是。用户需要的不是"吉凶"而是"怎么办"
4. **取向随场景变**：同一个龙逃走，在婚姻和谈判里是完全相反的意思——先定场景再取象
5. **大局 > 单宫**：先交代背景节奏，再列主用神、约束和具体救应条件
