# 五层主流程与六维校验

依据《奇门阳盘标准断局》与《奇门综合终身盘》两份项目原稿的 SKILL.md。“竖看、横看、远近、高低、多重用神、信息同步”沿用原名。本包通用框架采用时家阳盘拆补法。综合终身盘原有的阴盘转宫等规则只在另选相应体系时使用。

| 五层 | 执行与六维校验 |
|---|---|
| 定局 | 核对输入、法门、阴阳遁、局数、旬首、空亡、值符值使，再看星门伏反吟、五不遇、天显。记录问事时刻或出生时刻的来源与精度。 |
| 定位 | 记录所问事项、当事人、谁先行动、主用神及理由。横看日干、时干、年命、值符值使和事项用神。年命缺失时标未提供。一盘多问须分别取用神。 |
| 定象 | 竖看重点宫的星、门、神、天地盘干。就该问题解释主干与寄干；明确哪个角色取哪个干。多重用神依原法尽量交叉观察至少三个核心用神，同宫或共用一个原始信号时只登记一次。 |
| 定势 | 高低查月令、宫位、星门旺衰、刑迫制、墓库与空亡层次；远近查内外盘、主客、驿马与冲合。信息同步列同向证据和反例，无法消解的分歧标待定。 |
| 定策 | 将趋势写成有条件的判断、现实观察点和行动。应期写明所应事件、主窗口及理由、什么反馈会使判断失效。 |

正式断局的检查顺序依次为盘头、全局格局、用神、月令及生克、空亡与四害、天地盘克应、星门神宫合参、远近主客与应期。五层描述推导的任务，呈现可核对的盘面依据及结论即可。

## 校验字段的读法

- 竖看、高低使用“重点宫校验”。八宫原始盘可全览；只引用与本题用神有明确关系的事实。墓库、空亡分层是按该天盘干五行的月令初筛；甲所遁六仪与甲本身的旺衰含义分别注明。记录取用对象及其干、宫、月支、月令和旬空支；结合十二长生、同宫其他信号时须写出理由。旬空同宫两支只空一支时，应期按实际空支处理。混杂、边界未定或只有宫位时，墓库层次、真假空、救应均可填“待定”。
- 月支按节月，寅卯春、巳午夏、申酉秋、亥子冬、辰戌丑未属四季土。九星采用本包逐星月令表。干与门的季节强弱统一以当令五行定旺、所生为相、生令为休、克令为囚、令克为死。此为本版可复算口径；原八门分论的个别旺月附注有差异，引用其他规则时须并列注明。星月令、门月令、门宫生克、干的十二长生分别记录。
- 同一宫的多个角色共用一个旬空事实。不同星门不一定给出同向解释。救应写“条件／能减轻什么／仍存什么”；验证条件缺失时不得写已解。
- 应期只选与主用神或结果有关的线索。确有两种解释时写明两个窗口各自的触发条件和排除条件。库地和驿马取具体地支，对冲宫中另一支不得附带算入。没有可选窗口时明示“资料不足，暂不定应期”。
- 内外盘、人物角色、八神象意是传统取象；有关身份、他人行为、诊断等判断必须与可以核实的现实信息分列。严重限制不能被单一吉门、吉星或六合直接抵消。
- 输入时间按北京时间（UTC+8）解释，时分精度。异地时钟须先转换。节气时刻使用本包近似算法；用时间范围两端分别排出候选盘，若跨节、换日、换时辰则报告差异。资料仅能确定日期时，暂缓唯一时盘。外部盘与引擎有分歧时记录双方设置及受影响项目。确认一致的字段先用，剩余字段待核。

## 输出与验收

报告先写条件性结论。随后分别列“盘面直接显示”“多个信号综合判断”“不确定性与可验证条件”。逐条附用神、宫、主干或寄干以及可观察结果。盘面一致、规则实现与实际预测反馈分别记载。

终身局按出生盘独立处理。先登记生时可靠程度、出生地、真太阳时及换日设置、年命、起运宫、宫序、年龄边界。大运默认九宫数序，每段十五岁，前三个五年依次看九星、八门、十干克应。确需比较备选宫序时注明理由，以不同资料验证，保留默认宫序与差异。报告含命局总纲、人生阶段与大运、事业、财运、婚姻、家庭与父母、健康、优势、风险、关键转折和可执行建议。每项允许标“依据不足”。涉及健康写观察与就医核实；不得断寿限、具体死亡、疾病诊断或绝对人生等级。
