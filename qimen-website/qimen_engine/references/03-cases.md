## 一、终身局完整案例

### 案例4：1970年早逝例（伏吟·白虎冲命）

**出生**：1970年1月3日22时（己酉 丙子 癸未 癸亥）
**排盘**：阳遁一局，天心值符，开门值使（引擎验证 ✓）

**关键**：
- 大局伏吟 → 停滞不前
- 白虎落巽4宫，与日干宫乾6构成巳亥相冲 → 命宫受冲
- 日干宫克年干宫，太岁与日干互见刑克 → 早年多阻

**结论**：天心照命、开门吉门本为吉象，但日干伏吟+命宫被冲，整体以凶断，属**早年运势极弱之造**。

**教训**：吉星吉门不能抵消全局伏吟与命宫受冲；太岁与日干互克是强提示。终身局断凶时，语言上宜落在「运势低潮、宜守宜养、重点在防护」，不做具体事断言。

## 二、分类预测实例要点

### 求财实例

常见格局组合：
- **戊加丙（青龙返首）+ 生门旺相** → 求财大吉
- **辛加丁（狱神得奇）+ 生门** → 经商获倍利
- **戊加庚（值符飞宫）+ 生门空亡** → 换项目换地方的信号
- **日干入墓 + 壬癸 + 生门不旺** → 纵有利亦不得手，宜暂缓投入

### 婚姻实例

格局速断：
- **乙加辛（龙逃走）** → 多主女方主动求变
- **辛加乙（虎猖狂）** → 多主男方主动求变
- **六合逢空 + 乙庚相克** → 关系有名无实
- **休门旺 + 六合吉 + 乙庚相生** → 家庭和睦

### 官运实例

- **日干丁加丙+开门+值符** → 受上级赏识，有话语权
- **庚加戊（伏宫格）** → 进展受阻
- **开门入墓+空亡克日干** → 岗位变动或离任风险
- **反吟+开门临马星** → 工作调动频繁

### 疾病实例（仅作趋势参考）

- **天芮星生年命** → 恢复较顺
- **天芮星克年命** → 恢复较缓，宜早重视
- **天芮+死门+白虎** → 提示需重视，建议及时就医检查
- **年命旺相 + 天芮不克** → 体质基础较好

> ⚠️ 健康类问题一律建议以医学诊断为准，术数只作趋势参考，不作诊断、不给用药建议。

1. **书例四柱笔误（孕育不利例）**：书记「甲寅日」，独立锚点链（2000-01-01 戊午逆推）验证 1999-07-10 为**癸亥日**，书例四柱与日期差9天，局数（阴遁三局）也随错——引擎按真四柱排阴遁五局。断局逻辑已保留（S2-08）。
2. **书例节气划界疑误（地产项目）**：2001-09-01 书排阴遁九局（需白露上元），但白露交节在 9-7，9-1 应属处暑上元=**阴遁一局**。疑书用另一历表或时间笔误。
3. **书例日柱笔误**：书记「癸亥日」，锚点链验证 2004-07-13 为**癸巳日**（书内时柱丙辰与引擎一致，仅日柱差6天，疑字形近而误）。局数不受影响（阴遁五局 ✓）。
4. **书例局数与节气不符（造坟课）**：1996-04-04 书记阳遁一局，但该日属春分中元（阳九局）；且辛未时属甲子旬应空戌亥，书标午未空——书例内部矛盾，已标注入库（S3-22）。
5. **晚子时口径差异**：部分民间案例起局在 23:00-24:00，书例日柱取次日（如 8-26 23:27 记甲辰日=8-27日柱）——**晚子时换日派**，与本引擎默认 `zi_mode='change'` 一致 ✓。

> 教训：书例四柱/局数必须经引擎锚点链交叉验证后才可入库；凡不一致先查书例笔误、再查流派口径，最后才怀疑引擎。

route('求财')              # 预测类 → 事项域 → 原著类别 → route候选数
