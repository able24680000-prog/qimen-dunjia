# 操作流程与检查清单

## 一、排盘完整流程（拆补法）

### Step 0: 必备口诀

**日上起时法（五鼠遁元）** —— 根据日干求时柱天干：

> 甲己还加甲，乙庚丙作初。
> 丙辛从戊起，丁壬庚子居。
> 戊癸何方发，壬子是真途。

即：甲日/己日→子时起甲子；乙日/庚日→子时起丙子；丙日/辛日→子时起戊子；丁日/壬日→子时起庚子；戊日/癸日→子时起壬子。

**年上起月法（五虎遁元）** —— 根据年干求月柱天干：

> 甲己之年丙作首，乙庚之岁戊为头。
> 丙辛必定寻庚起，丁壬壬位顺行流。
> 若问戊癸何方发，甲寅之上好追求。

即：甲年/己年→正月起丙寅；乙年/庚年→正月起戊寅；丙年/辛年→正月起庚寅；丁年/壬年→正月起壬寅；戊年/癸年→正月起甲寅。月柱以节气（十二"节"）为分界，非农历初一。

### Step 1: 时间转换

- 输入：公历年月日时
- 输出：
  - 查万年历转为干支（年柱、月柱、日柱、时柱）
  - 确定当前节气（判断阳遁还是阴遁）

### Step 2: 定局（阴阳遁+局数）

- **阴遁/阳遁**：冬至到夏至→阳遁；夏至到冬至→阴遁
- **元数确定**：
  1. 看日柱天干——只可能是甲、乙、丙、丁、戊、己、庚、辛、壬、癸
  2. 找符头（日柱所在五天的第一天干支）：
     - 从日柱往前数，找到最近的甲日或己日，即为符头日
     - 如果日柱本身就是甲或己日，则日柱即符头
     - 例：日柱乙卯，往前甲寅是符头；日柱甲申，甲申即符头
  3. 看符头地支定三元：
  - 上元符头：甲子、甲午、己卯、己酉（地支子午卯酉）
  - 中元符头：甲寅、甲申、己巳、己亥（地支寅申巳亥）
  - 下元符头：甲辰、甲戌、己丑、己未（地支辰戌丑未）
- **局数**：查下表。

### Step 3: 排地盘（三奇六仪）

- 阳遁：从局数宫起，按「戊己庚辛壬癸丁丙乙」顺排九宫
- 阴遁：从局数宫起，按「戊己庚辛壬癸丁丙乙」逆排九宫
- 中五宫：阳遁寄艮8（生门）、阴遁寄坤2（死门）

### Step 4: 排天盘（九星）

- 确定值符星（时柱旬首对应的星，即六甲值符所在宫的原始星）
- 时干落宫 = 值符星飞到之宫
- 其余八星按固定顺序依次排入余宫

九星在活盘上的固定排列顺序（顺时针）：天蓬→天任→天冲→天辅→天英→天芮→天禽→天柱→天心→天蓬

其中天禽星寄于天芮星身边一起转动（中5宫随坤2宫）。

### Step 5: 排人盘（八门）

- 确定值使门（时柱旬首对应宫位的原始门）
- 从旬首时辰开始，阳遁顺数、阴遁逆数，数到所求时辰的地支 → 得到值使门落宫
- 其余七门按固定顺序依次排入余宫

**值使门落宫计算示例**（甲申旬，求测丁亥时）：

| 步骤 | 阳遁 | 阴遁 |
|------|------|------|
| 旬首甲申时 | 值使在甲申庚地盘宫（设为震3） | 同左 |
| → 乙酉时 | 酉时，阳顺：3→4(巽) | 阴逆：3→2(坤) |
| → 丙戌时 | 戌时，阳顺：4→5(中5寄坤2) | 阴逆：2→1(坎) |
| → 丁亥时 | 亥时，阳顺：坤2→乾6 | 阴逆：坎1→离9 |
| **值使落宫** | **乾6** | **离9** |

规律：每过一个时辰，阳遁顺走一宫，阴遁逆走一宫。从旬首地支所在宫起算。

八门在活盘上的固定排列顺序（顺时针）：休门→生门→伤门→杜门→景门→死门→惊门→开门→休门

### Step 6: 排神盘（八神）

- 值符随值符星落宫（天盘值符星所在宫即神盘值符所在宫）
- 阳遁：「值符→螣蛇→太阴→六合→白虎→玄武→九地→九天」顺排
- 阴遁：同上顺序逆排

**天禽星特殊处理**：天禽星始终跟随天芮星一起转动（中5寄坤2）。当天禽为值符星时，值符星飞到时辰天干所在宫，天芮星随天禽一起飞到该宫（而非相反）。非值符时，天禽在天芮之后一个顺位。

1. 求时辰的旬首（时柱所在旬的甲）
2. 旬首对应六仪：甲子→戊、甲戌→己、甲申→庚、甲午→辛、甲辰→壬、甲寅→癸
3. 找到旬首对应六仪在地盘何宫
4. 该宫的原始九星 = 值符星（如震3宫原始星为天冲）
5. 该宫的原始八门 = 值使门（如震3宫原始门为伤门）

## 二、断局四步法

天显按本包六甲时识别；伴星伏吟时列为次要提示。五不遇时须时干克日干且同阴阳，求财、出行、官司列为全局阻力，其余事项作情境提示。反吟优先描述反复与速度，主客利弊由主用神与行动先后判断。

### 第零步：盘眼识别——一眼定调（断局前必做）

> 盘眼 = 全局最影响决策的 1-3 个信号。**拿到盘先抓盘眼，再进四步**——这决定后续所有判断的基调。
> 程序化入口：`analyze.py → eye_of_pan()`（P0全局定调 → P1关键结构 → P2关键生克 → P3变动信号）。

| 优先级 | 盘眼 | 判断 | 基调 |
|---|---|---|---|
| **P0/P1** | 天显时格 | 六甲之时（时柱为甲X） | 伴星伏吟降为 P1；能否行动另查用神 |
| **P0/P2** | 五不遇时 | 时干克日干且同阴阳 | 求财、出行、官司为强阻力，其他事项作情境提示 |
| **P0** | 星门俱伏吟 | 星+门全归本宫 | 天地人俱静：宜守、利主、慢 |
| **P0** | 星门俱反吟 | 星+门全落对宫 | 天地俱反：反复、变化、快 |
| P0 | 仅星伏吟 / 仅门伏吟 | 只星或只门归位 | 环境不动但人事通道开 / 事推不动但天时有变 |
| P1 | 值符落空 / 日干落空 / 日干入墓 / 日干击刑 | 核心力量虚悬、自身不实、受困 | 先实后动，勿强行推进 |
| P2 | 日干宫 vs 时干宫生克 | 人可控事 / 事压人 / 相生 | 决定攻防方向 |
| P3 | 马星临身宫 / 用神宫门迫 | 变动将起 / 执行受阻 | 节奏提示 |

**抓盘眼三原则**：①主盘眼只有一个（最高优先级命中项）；②盘眼压倒单宫吉凶——主盘眼为「五不遇时」时，说明全局对本事项的约束，并核对主用神；③输出给用户时先说盘眼再说细节。

### 第一步：竖看——天时地利人和神助主客

逐宫竖看（特别是日干宫和用神宫）：

| 层次 | 检查内容 | 问题 |
|------|---------|------|
| 天时（九星） | 何星落宫？旺相休囚废？吉凶属性？ | 天时是否有利？ |
| 地利（地盘奇仪+十二长生） | 地盘何干？十二长生状态（长生/帝旺/死/墓等）？ | 地盘是否坚实？ |
| 人和（八门） | 何门？与宫的生克关系？门宫相生还是门迫？ | 人事状态如何？ |
| 神助（八神） | 乘何神？吉凶属性？ | 有无无形助力/阻力？ |
| 主客 | 天盘干为客、地盘干为主，谁生谁克？ | 利主还是利客？ |

> **九星旺衰判断优先级**：断局时先看九星在落宫的旺衰（落我生之宫=最旺，规则见核心知识→1.4），再看月令旺衰。落宫旺衰决定"当下状态"，月令旺衰决定"趋势强弱"。二者一致则判断更确定，二者相背则取落宫为主、月令为辅。

**日干宫五等判定**：

1. 完全合局（四层全吉+吉格）→大富大贵
2. 基本合局（多数吉）→富贵
3. 半合局（吉凶各半）→中层
4. 失局但有气→下层劳动者
5. 完全失局（日干死墓绝/逢空）→穷苦

### 第二步：横看——生克制化

逐对检查生克关系（均以地盘宫五行属性为准）：

| 关系对 | 检查项 |
|--------|--------|
| 日干 vs 时干 | 事与人的关系 |
| 日干 vs 月干 | 与同事/兄弟的关系 |
| 日干 vs 年干 | 与上级/长辈的关系 |
| 日干 vs 值符 | 与直接领导的关系 |
| 日干 vs 开门 | 与工作单位的关系 |
| 甲子戊 vs 生门 | 资本与利润的关系 |
| 年命 vs 各用神 | 提高准确率 |
| 时干 vs 值使 | 事与执行过程 |

**值使门的独立评估**（值使门代表"办事过程"，需单独分析）：

1. 值使门落宫旺相 → 执行顺畅，过程吉利
2. 值使门落宫休囚/逢空 → 执行受阻，过程不稳定
3. 值使门生日干宫 → 办事过程有利于求测人
4. 值使门克日干宫 → 办事过程中有阻力
5. 值使门与用神宫的关系 → 影响事件推进的节奏
   - 相生 → 推进顺利
   - 相克 → 过程有波折
   - 比和 → 稳定推进

规则：相生/比和→吉；相克→凶（需具体分析谁克谁）

### 第三步：内外盘及伏吟反吟

**内外盘**：

| 格局 | 空间 | 时间 | 策略 |
|------|------|------|------|
| 日干用神均落内盘 | 近/本地 | 快 | — |
| 日干用神均落外盘 | 远/外地 | 慢 | — |
| 一内一外 | 较远 | 较慢 | — |

**伏吟反吟专项检查（星门分离 · 组合断法）**：

伏吟反吟必须**星、门分开看**，组合不同结论不同——星主天时环境，门主人事通道：

| 组合 | 判断标准 | 核心结论 | 策略 |
|------|---------|---------|------|
| **星门俱伏吟** | 星+门全在本宫（六甲时必然如此） | 天地人俱静，环境与通道全停 | 宜守不宜动、利主；行动策略=主客换位 |
| **仅星伏吟** | 星归位而门动 | 天时停滞但人事通道仍开 | 环境不动，人可小步试探推进 |
| **仅门伏吟** | 门归位而星动（六癸时常如此） | 事推不动但天时有变 | 等时机、换路径，勿硬推 |
| **星门俱反吟** | 星+门全落对冲宫 | 天地俱反，反复多变 | 按用神、主客和现实条件决定是否变动 |
| **仅星反吟** | 星落对宫而门归位 | 外部环境多变而内部节奏稳 | 锁紧内部节奏，防外扰 |
| **仅门反吟** | 门落对宫而星归位 | 内部人事反复而外部平稳 | 先理内部，再应外变 |

> **门伏吟的核心策略**：利主不利客 → 如果求测人是客方，须设法**主客换位**——让对方主动找上门、把谈判地点改到自己主场、拒绝当场决策并让对方后续跟进。换位成功则劣势变优势。完整推导示例见 `references/05-thinking-chain.md`。

> **伏吟的应期**：以冲为应期。伏吟逢冲则破，破则速成。

### 第四步：月令旺相休囚

- 用神落宫在月令上处于什么状态？（旺/相/休/囚/死/墓/绝）
- 结合旺衰判断吉凶程度
- 旺相约期：逢生旺之时为应期；衰败约期：逢休囚之时为应期


### 空亡专项判断规则

空亡（旬空）是断局的核心要素之一，除各预测类别的具体规则外，通用判断如下：

**空亡的本质**：暂时性的"虚"——所代表的事物存在但不实在、有但不可用、在但未发生。

| 空亡对象 | 含义 |
|----------|------|
| 用神落宫逢空 | 事体不实，须待填实（出旬或冲动）方可成 |
| 日干落宫逢空 | 求测人状态不稳，自身能量不足 |
| 时干落宫逢空 | 事之结局未定，当前谈论为时过早 |
| 值符落宫逢空 | 领导/上级不实在，或权力虚悬 |
| 值使落宫逢空 | 执行过程落空，事虽启动但无实质进展 |
| 开门逢空 | 工作单位不实或岗位虚设 |
| 生门逢空 | 钱财落空，有机遇但无实利 |
| 六合逢空 | 婚姻/合作有名无实 |
| 马星逢空 | 有动象但动不成 |

**空亡的应期**：填实（出旬之日）或冲实（对冲地支之日/月/年）为应期。

**空亡的例外**：落空结合月令先列真空或假空候选；复核分支与救应，填实后仍查现实进展。

### 多用神合参秩序（用神冲突时的裁决规则）

测同一事务常看 3 个以上用神，结论不一致时按以下**四序裁决**，不得跳序：

```
第一序 · 大局基调（盘眼压倒一切）
    五不遇时/星门俱伏吟/俱反吟等 P0 盘眼命中 → 核对节奏与适用事项，避免重复计权
第二序 · 求测人承受力（日干/年命）
    记录强弱、适用时段与限制，不作数值折算
第三序 · 主用神（类别用神第一顺位）
    主用神定「成败方向」
第四序 · 辅用神
    辅用神只作「过程与细节提示」，不推翻主用神结论
```

**冲突裁决细则**：
- 主用神吉、辅用神凶 → 以吉断，辅用神凶象转为「过程中需注意的环节」
- 主用神凶、辅用神吉 → 以凶断，辅用神吉象转为「可争取的转机点」并给出条件
- 吉凶各半且无盘眼定调 → 结论降级为「有条件成立」，**必须写出成立条件**（如"若能等到X月冲空则成"）
- 有救应时列出可减轻的具体限制、所需条件及尚存的不确定性
- 事业局命中开门等限制时，复核其归属、强度和救应；其他事项按本题用神处理
- **裁决完成必须回写一句**：本次合参以哪个用神为主、哪个用神转为过程提示——让结论可追溯

3. **组合公式**：开门数（千位）+ 戊宫数（百位）= 合理成交价

4. **反向验证**：如果此价低于报价，说明议价空间充足；高于报价则价格合理
5. **月令调整**：用神在月令旺→取大数；休囚→取小数

### 3.2.1 事业类"表面吉象"一票否决清单（防错关键）

以下情形即使日干临值符/太岁/开门同宫看似大吉，也必须判"事难成/不成"：

- **开门受制则吉不就**：开门落宫逢门迫（开门金落震3/巽4木宫受克）、空亡、或临天芮/天蓬/天柱凶星 → 工作机会名实不符，难落实。

- **时干弱或空亡无动向**：时干（所问之事）落宫休囚+空亡 → 对方无回应、事无实质进展，主不成。
- **职称类以天辅星为用神**：评职称/晋级时，天辅星=职称本身。天辅落空亡或受日干/时干克 → 职称不成；日干生天辅或天辅生/比和日干 → 能成。不可仅看日干旺衰。
- **日干弱是根本否决**：日干落宫休囚+空亡（真空）→ 自身能量不足，再吉的用神也难托起此事。
- **伏吟/反吟在事业类**：星门伏吟（利主宜静）→ 调动/求职暂不动、待时机；门伏吟尤忌客方主动。反吟提示变动快、易反复；反吟局也能成事（如复职、快速到岗），关键看用神生克而非仅看伏吟反吟。

### 3.2.2 "调动成 ≠ 调动好"区分规则

事业变动需区分"能否成"与"成后好不好"两问：

## 五、终身局专项

### 5.1 终身局排盘方法

终身局使用**出生时间**（非当前时间）起局，方法与普通时家奇门完全相同，但排盘后以出生日干为命主定位。

**关键区别**：
- 用出生年月日时替代当前时间
- 不取当前节气，而取出生日所在节气
- 排盘步骤与普通时家奇门完全一致（拆补法七步）
- 出生年天干=年命（终身局的核心用神之一）

### 5.2 终身局十四步断法

**第1步：首辨阴阳顺逆**
- 记录性别、阴阳遁和出生时刻依据。两项本身无法定一生顺逆。

**第2步：看值符星照命**
- 值符星（照命星）与日干所临星的关系
  - 值符生日干星 → 一生机遇多、得天时
  - 日干星生值符 → 一生付出多
  - 值符克日干星 → 环境压力大
  - 日干星克值符 → 不甘受制，有反抗精神
- 照命星本身吉凶（天禽>天心>天任>天辅>天冲>天英>天柱>天芮>天蓬）

**第3步：看大局**
- 天显时格按所伴格局复核，单项不承担终身结论
- 伏吟 → 进展慢，人生多停滞
- 反吟 → 起伏大，易成易败
- 星门伏吟 → 复核哪些阶段表现为重复与延迟

**第4步：竖看日干宫**
列星、门、神、干与宫内状态，写出对应机会、限制及待核事项。

**第5步：断发展方向（三吉门）**
- 日干临开门 → 宜从政、创业、公职
- 日干临休门 → 宜稳定工作、家庭为重
- 日干临生门 → 宜经商、从事实业
- 日干临其他门 → 看门类象（伤门=武职/竞争，杜门=保密/技术，景门=文化/宣传，死门=殡葬/不动产，惊门=法律/口才）

**第6步：断适宜职业**
- 以日干所临星为天赋（九星代表先天天赋，见核心知识→1.4九星分论）
- 以日干所临门为人事方向（八门代表后天发展领域）
- 星门一致 → 天赋与职业匹配，易成功
- 星门相背 → 所做非所爱，需调整

**第7步：断财运**
- 生门宫与日干宫的关系：
  - 生门生日干 → 一生财源不缺
  - 日干生门相生 → 努力可得财
  - 生门克日干 → 求财艰难
  - 甲子戊旺相 → 资本厚；休囚空亡 → 财薄
- 日干在内盘、生门在内盘 → 祖业难留，外地发展得财
- 日干在外盘、生门在外盘 → 离祖发展得财
