# 案例的原断与反馈

为同一张盘固定一个来源编号。不同网页的同盘转录登记来源关系；统计时合并。核盘材料只检验实际有原始证据的字段。事前判断单独登记日期、问题、主客、可观察结果、窗口、失效条件和原话。事后只追加反馈。比较宫序或调整规则另记版本及理由，不回改旧案。

在本包目录下执行，数据库位置由使用者选择。以下为虚构的接口用例。

```python
from casebook import record, feedback, read_case
original = {"来源":"教学示例","盘面":"练习盘 A","问题":"能否按期签约",
            "原断":"若审批在周三前完成，本周五前有望收到签章件",
            "可观察结果":"收到双方签章件","观察窗口":"11月16日至20日",
            "失效条件":"截至20日未收到；审批延迟单独记录"}
record("cases.sqlite", "demo-A", "事前判断", original)
feedback("cases.sqlite", "demo-A-1", "demo-A", "未命中", "截至20日未收到签章件", "11月20日")
print(read_case("cases.sqlite", "demo-A"))
```

重复原案编号由数据库拒绝。新信息使用新的反馈编号，保留所有观察日期。无原断或无时限的旧案可按“事后转录”记录；截至反馈时未找到只描述当时的观察，不能由此补写永久失踪、原因或去向。“结果未知”“无从评价”与“未命中”分开。
