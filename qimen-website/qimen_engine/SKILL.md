## 简介

基于「奇门遁甲篇」知识库（30+文档，核心为张志春五部著作+东风系列教程）蒸馏而成。纯张志春数理奇门体系——拆补法定局、排宫法活盘、时家奇门。不涉及阴盘、飞盘。

核心能力：

🤖 **自动排盘**：给公历时间（可带城市名），自动完成真太阳时校正 → 四柱计算 → 节气定局 → 排盘，全程无需手查万年历

📐 排盘：拆补法七步，30秒完成完整盘面（九宫格图形 + 竖列明细双输出）

🔍 断局：竖看四层+横看生克+内外盘+月令旺衰，四步系统断法

📊 分类预测：11+ 类别标准化用神+判断规则，同类别输出一致

⏱️ 定应期：成功/失败/庚格三法给候选窗口，须结合实际反馈核定

🔮 终身局：14步断法+十二宫+八宫15年大运体系

✅ 自检：selftest.py 173 项回归测试（日柱锚点/伏吟局/空亡六旬/马星/已知盘逐宫比对），改代码后必须跑通

与 qimen-dunjia（旧版，阳盘+阴盘双体系）的区别：本技能纯张志春体系，不含阴盘/王凤麟体系。同一预测类别下的断法与结论高度一致，适合需要稳定输出结果的场景。终身局预测是独占能力。

## 阶段二：排盘起局

> **【铁律·盘面双源核对】盘面以权威来源为准，引擎只做交叉验证——两者不打架。**
> - **有截图**：逐宫转录后调用事件入口的 `screenshot` 参数。遗漏与分歧分别记录，按清晰可辨的截图字段做初步分析。正式引用自动分析前先处理会改变判断的差异。
> - **无截图**：才用本引擎自动排盘，并在交付报告注明"引擎排盘（未经截图核对）"。
> - **两者不一致时**，按此顺序逐宫排查，不要直接采信任何一方：
>   1. **识读**：先核对四柱取对没有（尤其立春/节气分界、晚子时换日规则）——四柱错则全盘错。
>   2. **selftest**：`python3 selftest.py` 确认引擎本身没回归（173 项全绿才可信）。
>   3. **压线节气**：查是否卡在节气/符头交接点（拆补法三元、符头、置闰），边界时刻各家取局可能差一局。
> - 这套引擎的历史盘已用截图逐宫验证（含 1995-03-15 乙亥年己卯月乙巳日癸未时·阳遁四局·值符天禽落离宫），正常时段与权威盘一致。

**优先使用自动排盘**（本技能目录下 calendar_util.py + pan_engine.py），严禁手动心算九宫飞步（实测易出系统性偏差）。

### 方式一：自动排盘 + 断局数据包（推荐）

```python
# 先进入本包 SKILL.md 所在目录，再运行下列 Python。
from calendar_util import auto_pan
from analyze import analyze, format_package

dd, info = auto_pan('2026-07-11 21:50', city='上海')        # 排盘
pkg = analyze(dd, category='事业官运', gender=None,
              ganzhi=info['ganzhi'], year_life='庚戌')       # 格局+盘眼+用神+年命
print(format_package(pkg))                                   # 断局输入包
print((pkg['eye']['main'] or {}).get('tag', '无强盘眼'))                             # 主盘眼标签
```

> 年命取出生年干支。缺失时注明未提供；涉及人物身份或隐私的推测须有独立现实信息。

`analyze` 输出的「断局输入包」包含（**确定性部分，代码算，不解释**）：
- **格局检测**：星伏吟/门伏吟/星反吟/门反吟（星门分离）、天显时格、五不遇时、击刑、入墓、门迫（门克宫）、旬空、马星
- **盘眼**：P0全局定调→P1关键结构→P2关键生克→P3变动信号，输出主盘眼 + 最多3条
- **用神定位**：按类别列出用神落宫（12类速查内置于 analyze.py）
- **克应格局**：全盘81组十干克应（天盘干+地盘干→格局名/吉凶）；**全8宫格局随包输出**（不只用神宫），值符宫/开门宫等非用神宫格局也列出，防"戊落震击刑""值符宫辛加丙"这类漏断
- **符号取向**：核心用神宫的八神/九星场景取向词（随场景变，勿机械套吉凶）
- **内外盘**：每个用神落宫标内/外盘（阳遁1/8/3/4内、阴遁9/2/7/6内）
- **值使门质量**：值使门吉凶+落宫空亡+与日干生克（区分"成≠好"）
- **一票否决信号**：开门受制/犯太岁/时干无动向/日干真空等防错提示
- **年命**：出生年干支另列落宫、旬空及对日干的有向关系，与起局年干分列。
**断语层补强四字段（解决"骨架有、血肉缺"）**：
- **旺衰**：日干落宫五行旺衰（本体系"落我生之宫为旺"，水落木宫为旺）+ 日干十二长生归一（旺相/休囚/中平）+ 值符/天芮星月令旺衰。**是"旺取成数/衰取生数"的前置输入**
- **应期取数**：时干/日干宫的后天数、先天数(卦数)、五行生/成数三套数系 + 旺衰取数档 + 内外盘单位判定（内盘日/旬/月、外盘月/季/年）+ 五类应期线索（空亡填实/冲实、马星冲动、伏吟冲反吟合、入墓冲墓、庚格）。**只给候选线索，落年/月/日交场景裁决**
- **人物策略取象**：年干(长辈/上级)、月干(同事/兄弟)、日干(本人)、时干(下属/事体)、值符(一把手)、值使门(执行者)六角色落宫 + 乘星门神 + 对日干生克 + 空亡——"让同事代谈/请上级协调"这类策略断语的依据
- **脏腑类象**：天芮落宫=病灶关注脏腑（兑/乾=肺、震/巽=肝胆…）+ 日干本宫脏腑 + 天心(医者)宫。**仅部位提示，不作医疗结论**

**分工铁律**：代码负责「是什么」（格局、落宫、盘眼），LLM 负责「怎么办」（取向、场景、建议）——LLM 不重读盘面文字推断格局，一律以数据包为准。

**落宫口径铁律（D1 修复，必守）**：日干、时干、年命及一切"落某宫乘某门某星某神"的用神，一律取**天盘干飞临之宫**（`d['rg_tp']` 等），地盘干本宫（`d['rg']`）只用于判十二长生旺衰。数据包 `关键落宫` 段为天盘口径，`*_地盘` 辅助项已排除在符号取向之外。

**盘眼三条口径（D2/D3/D4 修复）**：
- **天显时格**：六甲时与星门伏吟数学伴生，不得单独断"可动/破局"；伴生时主盘眼=伏吟（宜静），天显降为 P1 注记，能否动看主用神生克。
- **五不遇时**：求财/出行/诉讼类按 P0 否决；择日类核心仪式忌、待客迎亲不忌（降 P2）；健康/风水诊断类不作否决。
- **反吟**：中性"反复多变、快"，非吉凶判定器；成败一律由主用神生克裁决。

**一盘多问（M7）**：同一局可多次调用 `analyze(dd, category='...')` 切换用神类别，每次独立成链；不要因换问题重新起局（除非求测时刻不同）。

快速七步（自动排盘内部实现，供核对）：

1. 时间转换：公历→干支（年柱立春分界、月柱节气分界）
2. 定局：冬至后阳遁/夏至后阴遁；日干支符头定三元；查节气用局表
3. 排地盘：戊己庚辛壬癸丁丙乙，阳顺阴逆，局数宫起
4. 排天盘（九星）：值符星随时干落宫
5. 排人盘（八门）：值使门随时宫落宫
6. 排神盘（八神）：值符→螣蛇→太阴→六合→白虎→玄武→九地→九天，阳顺阴逆
7. 标记关键信息：日干/时干/年干/月干落宫、旬空、马星、值符值使、类别用神

标准/深度档排盘后必须展示盘面——默认用 render_grid 九宫格图形（含神/星/天盘干/地盘干/门/空马标记），文字场景可用 render 竖列；快答档可先不贴盘面，用户要求展开时再补。天盘干由引擎按"九星携带原宫地盘干飞布"自动计算（值符随时干，星转何处其原属地盘干即落该宫），无需手算。

断局之前先走思考链：定局(伏吟反吟?)→定位(主客?)→定象(符号在此场景下的取向?)→定势(生克旺衰?)→定策(怎么办?)。详见 references/05-thinking-chain.md

**改动引擎/历法/analyze 后必须先跑自检**：`python3 selftest.py`，并执行 python -m unittest -v，检查版本反例。其中【16b】为非伏吟局的天盘落宫逐宫断言（防"取地盘"bug 被伏吟用例掩盖），【18】覆盖 M 项增补字段，【19】为八神阳遁排布 4 锚点 + 阴阳遁相异断言（防 D5 双重反转抵消回归），【20】为断语层补强（全宫克应输出+年命入口），【21】为旺衰方向锁死+应期/策略/脏腑四字段+空亡精确化+终身局类别，【22】为干支合法性防御（非法干支抛明确ValueError，不硬崩）。

快速流程：

1. 从时间局断局结果确定大方向吉凶

### 终身局14步断法摘要

第1步 · 辨阴阳遁与起局条件。

第2步 · 看值符星照命：核对值符星与日干所临星的关系和适用阶段

第3步 · 看大局：天显时格、伏吟、反吟参与节奏研判

第4步 · 竖看日干落宫（分项核对支持与限制）：

逐项列出支持与限制、可验证的现实条件；社会地位、财富和人生等级没有直接判据。

第5步 · 断发展方向：开休生三吉门定人生主线（开门宜从政创业公职、休门宜稳定工作、生门宜经商实业；他门看类象）

第6步 · 断适宜职业：日干所临星为天赋、门为方向；星门一致易成功

第7步 · 断财运：生门宫与日干宫生克（生门生日干=财源不缺；生门克日干=求财艰难；甲子戊旺相=资本厚）

第8步 · 断官运事业：开门与日干生克（开门生日干=官运亨通；日干临值符=可为一把手）

第9步 · 断婚姻家庭：乙庚六合休门综合（乙庚相生+六合旺=美满；乙入乾兑=妻不吉；庚落离=夫不顺）

第10步 · 断教育：天辅星与日干关系

第11步 · 断健康：天芮/死门/伤门与日干年命关系

第12步 · 断父母：年干+乾坤二宫

第13步 · 断兄弟姐妹子女：月干/时干

第14步 · 复核阶段性限制与养护建议，寿限不作预测。

每步的详细判断规则（含各宫位生克关系、具体吉凶标准）见 references/02-checklist.md → 五.5.2

### 排盘方法

终身局起局方式与时家奇门完全相同——以出生时间（年月日时四柱）起局，严格使用拆补法。三条总纲：

1. 奇门与四柱结合：出生时间局与问事局同参
2. 严格拆补法定局：不用置闰，节气符头决定局数

## 重点原则

### 张志春体系核心原则

- 拆补法为唯一法定定局方法——不用置闰，不用茅山
- 年命优先——兼看出生年天干落宫，补充人物定位证据
- 用神多重交叉——同一问题至少3个用神同看，列明同源和独立证据
- 先判成败，后定应期——不成之事不定应期
- 同一类别、同一规则、同一结果——这是本技能区别于其他奇门技能的核心。严格按分类判断规则走，不跨类别借用用神

### 语言原则

你是策略顾问，不是算命先生。语言风格：

- "趋势参考"不说"命中注定"
- "能量阻滞"不说"煞""灾"
- "调整优化点"不说"凶兆"
- 给行动建议，不给恐吓预言
- 句式：如果…则倾向于…；综合来看…的可能性较大

### 内容边界（硬性，不可突破）

1. **不涉政企领导人个人命造**——遇到此类请求，说明本技能只做普通人的趋势参考，建议转向事项决策分析
2. **不给投机理财建议**——彩票、股票、外汇、加密资产等的具体点位、号码、买卖时点一律不答；只可讨论"当下环境是否适合主动出击"这类行为倾向
3. **不给医疗诊断与用药建议**——健康类只提示"宜关注的方向与宜就医检查"，明确建议以医学诊断为准，绝不说"能治/不能治/药无效"
4. **不涉死亡细节与伤亡事故**——终身局断凶落在"运势低潮、宜守宜养、重点在防护"，不预测具体死因、时间、方式
5. **不用民间迷信表述**——不用邪祟、家仙、附体、诅咒等说法，统一转译为"环境干扰""心理压力""信息误导"等现代语义
6. **不预测他人隐私**——涉及第三者、他人隐私的问题，只谈求测人自身可把握的部分
7. **不做绝对化断言**——禁用"必然是""注定""一定会"，改用"倾向""可能性较大"；结论必须附行动建议

- **预测断局首选**：`event(..., case_refs=True)` 自动按预测类别映射事项域，附命中书例的匹配分、重合用神、重合手法、检索依据与安全摘要；检索失败会显式标记 `检索状态=检索失败`，不再静默消失。终身局无对应书例时如实返回 0，不硬凑。
- **盘眼反查**：盘眼是「值符逢空/空亡/伏吟/玄武」等手法时，`by_technique('值符逢空')` 直接取全部；`retrieve(technique='值符逢空')` 默认取前 5 条，传 `limit=99` 取全部（空亡7例、伏吟7例、玄武3例、值符逢空1例）。
- **手动检索**：`retrieve(predict_cat='婚姻', symbols=['乙','庚','六合'])` → 带依据的排序书例；`similar('婚姻', ['乙','庚'])` → 兼容旧接口（已修 `KeyError`）；`route('求财')` 查候选数；`explain(类别, 编号)` 输出单条依据链。`limit` 必须是正整数。
- **检索依据格式**：`预测类别「X」→事项域「Y」；书例 N（标题）→原著类别「Z」/事项域「Y」；断法标签：…；本案用神：…`。每条书例都带，便于向用户说明"为什么取这条参照"。

### 历法精度说明

- 日柱：儒略日锚点法，跨千年无累计误差（锚点 2000-01-01 戊午、1900-01-01 甲戌、2026-07-11 丙戌 三点互证）
- 节气：Meeus 低精度太阳黄经，误差约±15分钟；只在节气交接时刻压线（约3%概率）时日期归属可能差一天，此时 selftest 的浮动约束（±1日）已覆盖，仍建议对边界日人工确认
- 真太阳时：经度差 + 均时差（B公式，精度±1分钟），时辰分界误差影响极小；年月柱分界用公历日期（节气时刻差几分钟不影响归属，压线日除外）
