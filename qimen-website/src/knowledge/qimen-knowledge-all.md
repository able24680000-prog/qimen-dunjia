## 一、底层认知框架（阿未视角）

### 奇门是认知方式，不是算命工具
阿未原话：**"奇门就是一种认知方式，借助一个脉络分析因果，就像截断的树，依然能够看到纹理的生成。"**

盘是静态切片，但它记录了"怎么长到这里"的因果。读盘是读"成因"，不是读"结果"。

### 八神不是吉凶标签，是"力的类型"
- 值符 = 稳定的主导力
- 白虎 = 尖锐的冲击力
- 太阴 = 隐藏的谋划力
- 九天 = 向上的扩张力

**所有力都是中性的**，关键在你怎么用它。白虎在竞争对手身上是打压，在项目攻坚期是推你一把。

### 拆解矛盾就是预测
阿未原话：**"核心是看这个能量是什么主导，以及它的矛盾，去拆解矛盾的过程，就是在预测。"**

目的不是输出"吉/凶"，而是：识别主导力 → 识别冲突力 → 拆解冲突。

### 盘是切片，但要看对宫和转宫
- **对宫** → 反面的力、互补面
- **转宫** → 牵连关系、源头
- **值符+值使+时干** → 同时撒网，不是线性看完一个再看另一个

## 三、四层盘关系（麦垛核心框架）

### 神 > 星 > 门 > 宫的权重层级
**神盘权重最高**（"神助大于一切"），其次是九星（天时），再是八门（人事/行为），最后是宫位本身。

但实战中全盘联动，不能只看一层。

### 九星旺衰判定（核心口诀）
来自《烟波钓叟歌》：
```
与我同行即为相，我生之月诚为旺。
废于父母休于财，囚于鬼兮真不妄。
```

以天蓬（水）为例：
- **旺**（生我者）：飞临震巽木宫 → 水生木，最能发挥
- **相**（同行者）：飞临坎水宫 → 比和
- **休**（我克者）：飞临离火宫 → 水克火但吃力
- **废**（生我者）：飞临乾坤金宫 → 金生水，自身不作用
- **囚**（克我者）：飞临坤艮土宫 → 土克水，被压制

**旺衰首重落宫（空间）、兼看月令（时间）。长期看落宫，短期看月令。**

### 门宫关系四层逻辑

| 关系 | 五行逻辑 | 深层含义 |
|---|---|---|
| 迫（门克宫） | 人强行改变环境 | 遇到阻力 |
| 制（宫克门） | 环境制约人 | 被外部压制 |
| 和（门生宫） | 人主动适应环境 | 和谐共生 |
| 义（宫生门） | 环境滋养人 | 得道多助 |

口诀：**吉门遇迫吉不就，凶门遇迫事更凶。**

### 暗干系统
暗干（八门含干）藏在人盘之下，代表表面之下的**潜意识动机**和**备选路径**。
- 排布：值使门起，阳顺阴逆布地盘时干
- 解读重点：暗干+天干的组合 = 内在动机 + 表面行为的矛盾统一

### 读象三步法
1. **寻根**：定用神、定宫位
2. **组次**：看星→门→神→干的主次关系
3. **定方向**：综合五行生克、旺衰给出结论

## 四、断卦流程（标准版）

### Step 1: 确认基础
- 节气、阴阳遁、局数、符头是否正确
- 一盘只问一事

### Step 2: 取值符+值使
- 值符 = 大局趋势、主导力
- 值使 = 执行路径、中间过程

### Step 3: 定用神
- 日干（自己）、时干（事体）、年命（先天命数）
- 分类用神：开门（事业）、生门（财运）、六合（婚姻）等

### Step 4: 看落宫
- 神盘→星盘→门盘→地盘，从外到内
- 看旺衰、迫制、空亡、马星

### Step 5: 找矛盾
- 用神宫的对宫是什么力
- 值符与值使是否有冲突
- 关键矛盾点是什么

### Step 6: 给建议
- 不直接说"吉/凶"
- 给推进/暂缓/换路径/补证据四个方向

## 五、特殊格局

### 伏吟
天盘地盘相同 → 能量冻结、停滞。宜守不宜攻。
- 值符伏吟：大局不动
- 门伏吟：人事停滞
- 星伏吟：资源冻结

### 反吟
天盘地盘对冲 → 能量对冲、反复。宜快不宜慢。
- 值符反吟：大局反复
- 门反吟：事有回头
- 星反吟：资源动荡

### 九遁格
特殊能量通道，条件苛刻：
- **天遁**：丙+戊 + 开门/生门
- **地遁**：乙+己 + 开门
- **人遁**：丁+戊 + 休门/生门
- **风遁**：乙+辛 + 巽宫
- **云遁**：乙+辛 + 坤宫
- **龙遁**：乙+壬 + 坎宫
- **虎遁**：庚+辛 + 艮宫/兑宫
- **神遁**：丙+壬 + 九天
- **鬼遁**：丁+乙 + 九地

## 七、财富与事业专题（麦垛核心）

### 发财/破财判断
- **戊** = 本金、资本
- **生门** = 利润、收入
- **开门** = 事业机会
- 戊+生门同宫且旺相 → 正财
- 戊+开门同宫 → 升职加薪
- 戊临玄武/天蓬 → 防破财
- 生门被克或空亡 → 收入不稳定

### 事业升迁
- 开门+太阴+丁 → 暗中调动
- 开门+值符 → 老板器重
- 开门+白虎 → 竞争上位
- 开门空亡 → 机会落空

## 八、案例库（精选）

### 案例001：天气预测
- 规则：天蓬+天英+壬癸+坎/离宫 + 白虎/玄武/九地 → 雨
- 天辅+天冲+巽震宫 → 风
- 天英+景门+离宫 → 晴

### 案例002：测来人相貌（九星定体形体系）
- 先看旺衰再定形
- 地盘天干定主色，天盘天干定辅色
- 星在旺地特征明显，囚地反向
- 值符主稳、腾蛇主变、太阴主内、九天主高

### 案例003：断来人
- 多人场景：时干宫第1人，值使宫第2人，中5/值符宫第3人
- 取数看空亡马星
- 全盘扫描清单：值符→值使→时干→中5→年命→空亡马星
