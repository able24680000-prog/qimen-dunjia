# 时家奇门 v2.6 事件分析

`/shijia` 使用 `POST /api/qimen`。分析引擎来自用户提供的《时家奇门 v2.6》；九宫盘和报告同由 v2.6 生成，不复用 `/divination` 的旧版 JS 盘面或评分。旧盘面与本版本有已知值使、天禽寄宫差异，不能混合解释。

仅支持时家阳盘、转盘、拆补法，界面输入为北京时间、子时换日，不自动使用真太阳时。输入包括日期时间、事项类别、问题和可观察结果；期限、急缓、先动方可选。所问与可观察结果会以 POST 发送到本站服务端计算；程序不主动持久化，响应禁用缓存。请勿承诺托管商没有请求日志。

`api/qimen.py` 适用于 Vercel 的 Python Function；前端 Vite 静态构建不提供该 API，`npm run dev` 单独运行无法调用 Python。部署需以 `qimen-website` 为 Vercel 项目根目录，并启用 Python Function。其他平台须提供等价的 Python 服务与 `/api/qimen` 路由；API 不可用时前端明确报错，不退回旧算法冒充 v2.6。部署与线上接口尚需在实际托管平台验证。

当前随仓库接入事件分析所需五个 Python 核心文件。原始书例检索库、截图转录、终身局、可选真太阳时与其他起局法没有接入网站，不能称为完整 Skill 功能。输出为算法生成的线索，模型信心/分数不代表实证准确率。

运行 `python3 -m unittest discover -s tests -v` 检查接口模型，`npm run build` 检查前端构建。
