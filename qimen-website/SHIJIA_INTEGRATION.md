# 时家奇门 v2.6 接入说明

`/shijia` 使用 `POST /api/qimen`，统一调用用户提供的时家阳盘、转盘、拆补法 v2.6。旧 `/divination` 的排盘算法与 v2.6 已知存在值使与寄宫差异，两个入口不能混合盘面和断语；现仍保留旧版供对照。部分传统转宫法并无可验证的自动裁决程序，界面只并列星门神干供人工复核。

## 功能与边界

- 事件分析：12 类事项、细分问项、主用神、年命、性别、代问角色、事项阶段、急缓、行动先后、期限；允许时间起局或手工四柱与局式。请求问项命中多个细项时保留待核。
- 日历口径：默认北京时间、23 时换日、不校正真太阳时；可选 0 时换日、输入经度校正真太阳时和手工局式。北京时间之外的本地时间需先换算为北京时间。非拆补、阴盘不在本引擎支持范围。
- 终身局：支持日期未知时辰降级、九宫数序/地理顺时针对照、阶段及事业/财运/婚姻/健康专项数据包。年龄分段须另行确认年龄算法，父母和家庭的完整自然语言分析仍需结合现实信息和人工判断。
- 截图核对：本包的 chart_review 处理**人工转录**，不具备图片 OCR。已读、未知、明确空值和差异分开显示；未完成核对的转录不自动成为已确认盘。
- 同类书例：由本包原著案例模块检索并返回安全摘要，不应当作预测准确率或直接套用结局。
- 案例复盘：原包 SQLite casebook 模块保留供本地使用；Web 版存于浏览器 localStorage，事前记录必须包含原断、观察窗口和失效条件，反馈单独追加，支持导出 JSON；不支持跨设备同步或自动备份。
- 转宫：选择用神原宫与目标宫，原盘的星门神干并列比较；不自动判断吉凶、不输出未经验证的最优选项。原资料保留在 `qimen_engine/references/04-zhuangong.md`。
- 源文件、原书例数据库、资料与原包测试均保存在 `qimen_engine`。公开服务不开放原书全文读取接口；书例只返回经原 Skill 的安全摘要。

所有输入以 POST 发送至本站服务端进行计算，API 不主动持久化、响应禁用缓存，但无法保证托管商没有请求日志；不要输入不必要的敏感信息。传统文化模型的分数或信心不是经独立验证的概率，历史小样本回测不能外推为准确率。

## 部署与测试

`api/qimen.py` 按 Vercel Python Function 约定编写，须以 `qimen-website` 为项目根目录，且需部署平台支持 Python Functions。其他平台须提供等价的 Python 服务与 `/api/qimen` 路由。独立 `npm run dev` 不提供该接口；接口缺失时不回退旧算法。正式托管环境和线上接口仍需实际验证。

在此目录运行：`python3 -m unittest discover -s tests -v`、`python3 qimen_engine/selftest.py`、`python3 -m unittest discover -s qimen_engine`、`npm run build`。自检通过只表明固定回归用例通过，并不证明预测准确。
